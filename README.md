# Campus Life

A clickable concept app for **Ashgrove University**, a fictional liberal-arts school (home of the Weavers). It runs entirely in the browser on demo data. No server, accounts or build step.

## Run it

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Files

| File | What it holds |
| --- | --- |
| `index.html` | Page shell: phone frame, header, tab bar |
| `css/styles.css` | All styles, including light and dark themes |
| `js/app.js` | Demo data, screens and interactions |

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Notes

- All people, companies, phone numbers and records are fictional demo content.
- Each visitor's changes are saved only in their own browser. **Me → Reset demo data** restores the defaults.
